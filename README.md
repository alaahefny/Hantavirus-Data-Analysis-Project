# Advanced Data Analysis Portfolio: SQL & Excel Ecosystem 🌍📊

## 📌 Project Overview
This repository showcases a comprehensive collection of end-to-end data analysis projects, transitioning seamlessly from initial data processing in **Microsoft Excel** to advanced query optimization and business logic implementation using **SQL Server (T-SQL)**. 

Rather than focusing on a single domain, this portfolio analyzes multiple real-world datasets—ranging from global healthcare monitoring (such as the **Hantavirus Global Surveillance Dataset**) to digital user behavior and platform engagement analytics. This diversity demonstrates my ability to adapt analytical methods across various industries, leveraging my background in Geography to extract meaningful spatial, environmental, and behavioral insights.

> 🔄 **Note:** This repository is actively maintained and **updated every month** with new datasets, advanced queries, and interactive dashboards.

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Advanced Data Cleaning, Transformation, Pivot Tables, Pivot Charts, and Initial Performance Dashboarding.
* **SQL Server (T-SQL):** Multi-table Analysis, Common Table Expressions (CTEs), Aggregate Filtering (`HAVING`), Conditional Data Categorization (`CASE WHEN`), and Complex Joins/Groupings.

## 🔍 Key Insights & Analysis Across Datasets
1. **Epidemiological & Spatial Impact:** Isolated global virus hotspots by aggregating total healthcare cases per country and region using `GROUP BY` and `ORDER BY` descending sequences.
2. **Behavioral Segmentation & Engagement:** Applied complex `CASE WHEN` conditional logic inside Common Table Expressions (CTEs) to segment user behavior and clinical metrics into custom activity/risk levels (`very heavy`, `moderate`).
3. **Advanced Trend Filtering:** Utilized `HAVING` clauses combined with aggregate functions (`MAX`, `COUNT`) to pinpoint specific performance trends and platforms exceeding critical operational thresholds.

## 📁 Repository Structure
* `HANTAVIRUSE_DATA_ANALYSIS_PROJECT.xlsx`: Contains the processed datasets, automated formulas, pivot tables, and analytical charts for healthcare tracking.
* `HANTAVIRUSE_DATA_ANALYSIS.SQL`: The finalized, unified, and well-documented SQL script containing all advanced queries, multi-table analysis, and business logic.
